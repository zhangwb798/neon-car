# 指尖赛车 · Neon Circuit

本游戏由找网吧游戏工作室制作。无依赖的静态 HTML / Canvas 赛车游戏。

## 操作

手机横放，右侧固定摇杆控制方向和油门，左侧手刹用于制动和快速转向。电脑使用 WASD / 方向键，空格手刹。车辆第一次实际移动时开始计时，暂停会冻结时间。

## 二十条特色路线

全部关卡合并在一个列表，不设漂移分组，按路线长度排列。包含微光环线、折返之间、阶梯山城、午夜回廊、机场折返、海岸长风、山间折线、锯齿街区、城市穿梭、双发夹山口、沙丘天际、碎石迷廊、针眼连环、闪电回旋、断崖急落、极夜远征、月牙环湾、蝶形立交、螺旋深井和终极拼图。每条路线有不同的弯道结构和节奏，取消旧版重复缩放路线。

保留路线的三星时限按上一版乘以 80% 并四舍五入至 0.01 秒；新路线使用相同强度的模拟参考校准。二星和通关倒计时保持宽松。沿途每个时钟增加 1.5 秒倒计时，不直接降低星级使用的实际驾驶时间。

每关最多三颗星，完赛奖励 10 金币，提升历史最佳星级额外每星 20 金币。通关可直接点击下一关，失败可重试，最后一关不显示下一关。车身、轮胎印、拖尾各六款，独立购买装备。保存的路线按名称迁移，金币和皮肤保留。

## 音效

Web Audio 实时合成随速度增强的轮胎摩擦噪声；漂移时加强摩擦，高速手刹有更强的刹车噪声和啸叫。拾取时钟触发双音叮声。默认开启，首次点击开始驾驶后由浏览器解锁，可在右上角关闭；暂停、结算、离开页面时停止持续声音。

## iPhone 图标与封面

在 Safari 打开网站后通过分享菜单添加到主屏幕。提供 Apple touch 图标、Web Manifest、八组横竖屏原生启动图，以及约两秒的网页制作署名封面。系统原生启动图是否使用由设备和 iOS 版本决定。

## 部署

GitHub Pages 通过附带的工作流上传 dist，每次运行使用独立部署包名称。也可直接打开 dist/index.html 本地游玩。
