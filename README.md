# 指尖赛车 · Neon Circuit

无依赖的 HTML / CSS / Canvas 2D 静态竞速原型。打开 dist/index.html 即可游玩，也可把 dist 部署到 GitHub Pages、Cloudflare Pages 或其他静态托管平台。

## 操作

进入赛道后保持待发状态，车辆第一次实际移动时才开始计时。仅按下屏幕或摇杆处于中心死区不会起表。起步后松手、停车均继续计时；暂停冻结计时，重来恢复待发状态。

- 手机或鼠标：在右下角固定摇杆按下并拖动，偏移方向控制车头，偏移距离控制加速度；松手减速。
- 电脑：WASD 或方向键控制方向和加速，空格辅助漂移，Escape 暂停。
- 放大跟随镜头始终将赛车保持在画面中心，右上角小地图显示路线、车头朝向和下一个检查点。
- 44 条赛道，按实际长度逐渐增长，从约 1.9 km 到 12.9 km。包含环线与起终点分离的开放路线。
- 三星时间基于固定 120 Hz 驾驶物理，每关模拟八种提前转向距离，采用最快参考成绩加 60% 余量和 2 秒；它是模拟参考，不是全局最优路线证明。二星为参考成绩加 100% 余量和 3 秒。
- 路线中心每约 500 个世界单位设置一个小时钟，拾取后增加 1.5 秒倒计时，每个时钟仅能拾取一次。星级按实际驾驶时间计算，道具不直接降低三星用时。
- 初始倒计时为模拟参考成绩的 240% 加 6 秒，时钟提供额外容错。按顺序经过路标到达终点。
- 六种车身、六种轮胎印和六种拖尾，可独立购买与搭配。每次完赛奖励 10 金币，每提升一颗历史最佳星额外奖励 20 金币。
- 星星、最好成绩、金币与车漆保存在当前浏览器 localStorage 中。

新版按原始用时重新评定旧关卡星级，保留金币和已购买的皮肤。显示距离是游戏世界中的距离标尺，不对应真实赛车物理尺度。

音效默认关闭，可在右上角开启。触感反馈取决于设备与浏览器是否支持 Vibration API。

## GitHub Pages

将本目录推送到 GitHub，仓库设置中启用 Pages / GitHub Actions。附带工作流会把 dist 作为静态页面部署。部署 URL 由 GitHub 生成。

## 急漂移路线

新增 12 条不规则路线：锯齿街区、双发夹山口、碎石迷廊、闪电回旋，各三个长度。赛道选择中使用新增急漂移筛选即可查看。
手机按住屏幕上的漂移按钮，电脑按住空格，可以制动并提高车头转向速度。急弯旁有提示，松开按钮恢复正常加速。
旧存档按赛道名称迁移，保留历史成绩、金币和皮肤。

## 横屏操作

手机横放游玩，左下角为手刹，右下角为固定方向/油门摇杆，支持两指同时操作。摇杆松手回中，车辆减速。手机竖屏时显示横放提示；比赛中旋转回竖屏会暂停并清空触控状态。手刹支持按住漂移，电脑保留 WASD/方向键和空格。

## iPhone 主屏幕与启动封面

通过 Safari 分享菜单添加到主屏幕。提供 180px Apple touch 图标、192/512px应用图标、Web Manifest和八组 iPhone 屏幕尺寸的横竖屏原生启动图。系统启动图是否显示由 iOS 版本与设备匹配决定。网页自身也会显示制作署名封面，约 2 秒自动进入，点击或按 Enter 可跳过。
封面文字：本游戏由找网吧游戏工作室制作。图标和启动画面均使用已有游戏的深色、荧光绿视觉。
